Stock Portfolio Tracker

Project Overview

This project was developed as part of the CodeAlpha Python Programming Internship.

The Stock Portfolio Tracker helps users manage their stock investments by calculating investment values based on stock prices and quantities entered by the user.

Features

- Add multiple stocks
- Enter quantity for each stock
- Calculate investment value automatically
- Generate portfolio summary
- Save report into a text file
- Handle invalid stock entries

Technologies Used

- Python
- Dictionaries
- Loops
- Conditional Statements
- File Handling

Learning Outcomes

- Dictionary Operations
- User Input Handling
- Loop Implementation
- File Handling
- Problem Solving
